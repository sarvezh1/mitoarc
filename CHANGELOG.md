# Changelog

All notable user-facing changes to MitoArc are documented here.

## 1.0.0

- Added paired-end FASTQ and validated pre-aligned BAM/CRAM entry modes.
- Added full-reference alignment, mtDNA extraction, depth/QC, and standard plus shifted-coordinate processing.
- Added GATK mitochondrial Mutect2 and independent mutserve2 call paths with caller-preserving comparison.
- Added an experimental NUMT mapping-confidence and fragment-evidence framework.
- Added HaploGrep haplogroups, Haplocheck contamination assessment, functional annotation, and caller-specific consensus sequences.
- Added structured outputs, MultiQC, deterministic plots, and self-contained HTML reporting.
- Added compact controlled-benchmark definitions, source data, and regression tests.
